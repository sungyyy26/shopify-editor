# Shopify Editor

조건(제목/상태/태그/URL 핸들/템플릿)에 맞는 Shopify 상품을 찾아 제목·설명·태그·미디어를 일괄 수정하는 3단계 마법사 도구.

## 설정

1. Shopify Dev Dashboard에서 앱을 만들고 아래를 설정합니다.
   - Admin API scopes: `read_products`, `write_products`, `read_files`
   - 허용된 리디렉션 URL(s)에 `http://localhost:3000/auth/callback` 추가
   - API credentials(자격 증명) 탭에서 클라이언트 ID / 클라이언트 시크릿(암호) 확인
2. `.env` 파일 생성:
   ```
   cp .env.example .env
   ```
   그리고 `SHOPIFY_STORE_DOMAIN`, `SHOPIFY_API_KEY`(클라이언트 ID), `SHOPIFY_API_SECRET`(클라이언트 시크릿)을 입력합니다.
3. 서버 실행 (설치 필요 없음):
   ```
   node server.js
   ```
4. `http://localhost:3000` 접속 후 **Shopify 연결하기** 버튼을 눌러 OAuth 인증을 완료합니다. 완료되면 Admin API 액세스 토큰이 자동으로 `.env`에 저장됩니다.

## 사용 흐름 (3단계)

1. **조건**: 제목/URL 핸들/태그/템플릿/상태 중 하나 이상 입력하고 검색하면 즉시 조회 결과가 표시됩니다 (가장 최근에 수정한 상품 페이지 먼저 표시, 한 줄에 4개씩). URL 핸들은 여러 줄(또는 쉼표)로 여러 개를 한 번에 입력할 수 있습니다 (핸들 또는 전체 URL 모두 가능). 자주 쓰는 조건 조합은 **즐겨찾기**에 이름을 붙여 저장해두고 다음에 한 번에 불러올 수 있습니다. 이전 작업이 후보 조회만 하고 다음 단계로 넘어가지 않은 상태에서 새로 검색하면, 그 이전 작업은 작업 내역에서 자동으로 삭제됩니다.
2. **수정사항 · 선택**: 제목/설명(HTML)/미디어/태그 중 채울 항목만 저장한 뒤, 조회된 페이지 중 실제로 적용할 것만 카드에서 선택합니다 (기본 전체 선택). "전체 선택/해제" 외에 "현재 페이지 전체 선택"과 Ctrl(⌘)+A로도 현재 페이지에 보이는 항목만 한 번에 선택할 수 있고, 카드를 Shift+클릭하면 마지막으로 클릭한 항목부터 지금 클릭한 항목까지 범위를 (그 시작 항목과 같은 상태로) 한 번에 선택/해제할 수 있습니다.
3. **최종 확인**: 선택한 페이지 전체에 대해 무엇이 "적용"/"건너뜀"/"오류"될지 실제 API로 미리 계산한 TO-BE 미리보기를 보여줍니다. 결과가 전부 "적용"이면 적용 예시 1개를, "적용"과 "건너뜀"이 섞여 있으면 각각 1개씩을 리스트 위에 실제 AS-IS/TO-BE 값(제목 변경 전/후, 태그 변경 전/후, 미디어 변경 전/후 썸네일 등)으로 미리 보여줍니다. "최종 확인 · 적용 실행"을 눌러야 실제로 스토어에 반영됩니다.

검색부터 적용까지의 모든 작업은 하단 **작업 내역**에 5건씩 기록되어(6건 이상이면 페이지 넘김) 새로고침해도 남아 있습니다 (로컬 `data/jobs.json` 파일에 저장, git에는 커밋되지 않음).

## 수정사항 항목

- **제목/설명(HTML)**: 값을 입력한 필드만 수정됩니다.
- **미디어**: "+ 미디어 작업 추가"로 여러 작업(추가/교체/삭제/이동)을 한 번에 큐에 담아 순서대로 적용할 수 있습니다. **각 작업은 그 앞의 작업들이 이미 반영된 상태를 기준으로 계산됩니다** — 예를 들어 "1번 삭제" 다음에 "3번을 1번으로 이동"을 넣으면, 삭제로 인해 한 칸씩 당겨진 뒤의 3번(원래 4번째 이미지)이 이동 대상이 됩니다. 미리보기(Step 3)에도 이 순서를 그대로 반영해 계산합니다.
  방식에 따라 "정보" 필드가 가리키는 대상이 달라지므로 라벨이 자동으로 바뀝니다 (추가="등록할 이미지", 교체="교체할 이미지(기존)", 삭제="삭제할 이미지"). 값은 쇼피파이에 이미 등록된 이미지를 파일명/대체 텍스트로 검색해 가져오거나(입력 중 자동완성으로 정확한 값을 골라 오타 방지), "📁 업로드" 버튼으로 로컬 이미지 파일을 바로 올려 그 파일명을 이미지 제목으로 쓸 수도 있습니다 (업로드는 되도록 바로 이어서 저장·적용해주세요 — 업로드 직후 URL은 시간이 지나면 만료될 수 있습니다). "정보"는 Enter로 여러 개 추가할 수 있으며, 2개 이상이면 **"순서"도 쉼표로 같은 개수만큼 입력해 순서대로 1:1로 짝지어 서로 다른 이미지 여러 개를 한 번에 처리**합니다 (예: 정보 "A, B" + 순서 "2, 3" → A는 2번, B는 3번). 순서를 비워두면 추가는 맨 끝에, 교체/삭제는 위치와 무관하게 찾아서 처리합니다. 이미 같은 이미지가 해당 상품에 등록되어 있으면 자동으로 건너뜁니다.
  - **추가**: 지정한 순서에 이미지를 끼워넣고, 기존 해당 순서 이후 이미지들은 한 칸씩 뒤로 밀립니다. 순서를 비우면 맨 끝에 추가됩니다.
  - **교체**: "정보"(기존 이미지)를 "변경할 이미지"(새 이미지, 정보와 같은 개수로 입력)로 바꿉니다. 순서를 입력하면 그 위치의 이미지가 정보와 일치할 때만 교체하고(안전장치), 순서를 비워두면 위치와 무관하게 정보와 일치하는 이미지를 찾아 교체합니다(원래 위치 유지) — 같은 이미지가 여러 상품에서 다른 위치에 있거나 정확한 위치를 모를 때 순서를 비워두면 됩니다.
  - **삭제**: 순서를 지정하면 그 위치의 이미지 제목이 "정보"와 정확히 일치할 때만 삭제합니다 (다른 이미지를 잘못 지우는 것을 막기 위한 안전장치이며, 일치하지 않으면 건너뜁니다). 순서를 비워두면 위치와 무관하게 제목이 일치하는 이미지를 찾아 삭제합니다.
  - **이동**: 새 이미지를 등록/검색하지 않고, 이미 등록되어 있는 이미지의 순서만 바꿉니다. "정보"는 사용하지 않으며, "순서"(현재 위치)와 "이동할 위치"를 모두 입력해야 합니다 (배치 입력 불가, 항상 1개씩). 예: 순서 3, 이동할 위치 1 → 3번째 이미지가 1번으로 이동하고 나머지는 한 칸씩 뒤로 밀립니다.
- **태그**: 값을 비워두면 태그는 건드리지 않습니다.
  - **추가**: 기존 태그에 새 값을 더합니다 (중복 제거).
  - **교체**: 태그 전체를 입력한 값으로 바꿉니다.
  - **삭제**: 입력한 값과 일치하는 태그만 제거합니다.

## 참고

- 검색 결과는 최대 5000개(250개씩 20페이지)까지 조회됩니다.
- 미디어 "정보" 검색은 파일명은 전체 대상으로 검색되지만, 대체 텍스트(alt) 매칭은 쇼피파이 자체 검색이 alt를 지원하지 않아 **최근 등록된 이미지 50개** 내에서만 이루어집니다. 등록된 지 오래된 이미지를 대체 텍스트만으로 찾아야 한다면 검색되지 않을 수 있으니, 이 경우 파일명(또는 원본 파일명)으로 검색해주세요.
- 제목/태그/템플릿 조건은 Shopify 검색 문법과의 충돌(특수문자, 완전 일치만 지원 등) 문제로 서버에서 결과를 가져온 뒤 부분 일치("포함")로 다시 필터링합니다.
- 태그 조건에 쉼표로 여러 값을 입력하면 그 중 **하나라도 포함**하는 상품이 조회됩니다 (OR 조건).
- 상태 필터는 Shopify 관리자의 실제 상품 상태 3가지(활성/초안/미게시)를 그대로 사용합니다. "미게시"는 `status:unlisted`에 해당합니다 (문서화되지 않은 상태값이며, 흔히 알려진 ACTIVE/ARCHIVED/DRAFT 3가지와 별개입니다).
- 즐겨찾기 조건은 `data/presets.json`에 저장됩니다 (git에는 커밋되지 않음).
